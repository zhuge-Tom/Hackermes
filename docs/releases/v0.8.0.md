# Hackermes 0.8.0

Hackermes 0.8.0 继续把内置浏览器、CDP/Page Agent、Traffic 工作台、AI 助手与授权安全评估
整合为一个桌面工作台。本版重点是精确页面绑定、工具授权收紧、Page Agent 双世界运行时、
Traffic/Assessment 工作流与桌面界面可用性。

## 本版重点

- AI 工具始终绑定精确的内置浏览器 `pageId`；Console、Network、页面上下文与安全快照不会混入其他标签页数据。
- 新增有界 `page_security_snapshot`，只返回 URL/origin、表单与外链脚本元数据、安全响应头、CSP 和 Cookie 属性聚合，不返回敏感值。
- 浏览器派生的 Assessment 范围在人工确认前冻结目标，执行前复核 URL/origin；通用 `page_assessment` CLI 旁路已关闭。
- “本会话记住批准”按会话、工具、页面和参数指纹分组，并具有绝对有效期，切换页面或修改参数会重新进入策略检查。
- Page Agent 把 DOM 录制与 selector 迁入命名隔离世界，主世界保留必要观测 Hook；新增分片重组、容量、并发和超时保护。
- Traffic 的桌面、CLI 和 AI 入口改用共享 typed intent/outcome，去除字符串命令往返；网络列表和 AI 序列化均有明确上限。
- Assessment 提供 coherent case 原子快照，统一展示范围、计划、批准、任务、证据、Finding 与审计状态。
- 主窗口、AI 面板、Traffic 和 Assessment 完成浅/深主题、空状态、错误状态、最小窗口和响应式布局整理。
- 构建、测试、运行证据和发布包统一输出到 `G:\HackermesBuild`，并避免全局强制 npm/TEMP 缓存导致的跨项目锁冲突。

## 安全声明

Hackermes 仅用于自己拥有或已获得明确授权的目标。AI 调用主动工具时仍必须通过精确页面/目标范围、
参数绑定的策略检查、一次性批准与独立 ToolHost 校验。
