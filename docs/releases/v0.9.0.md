# Hackermes 0.9.0

Hackermes 0.9.0 强化了授权安全评估、流量工作台、Agent 上下文管理与审计可信链，并补齐复杂 HTTP 参数、报告签名和多操作者治理能力。

## 本版重点

- “全部授权”范围无需再填写具体范围名称、授权依据或操作者；目标统一归一化为 `*`，选择“全部工具”时逐项执行可用工具并汇总结果。
- Assessment 报告支持 ECDSA 签名导出、CLI/Agent/ToolHost 第三方离线验签，并增加审计密钥信任文件和轮换治理。
- 新增操作者身份目录、签名密钥命令入口以及更完整的授权、证据、Finding 和审计链工作流。
- Traffic 支持 multipart 表单参数、有界请求体处理、归档分页、工作区隔离、历史策略刷新和更丰富的复杂规则编辑。
- AI Agent 新增 ACP 主动上下文剪枝、会话持久化、工具调用协议强化、Token 用量展示及 OpenAI 兼容客户端韧性改进。
- Assessment 与 Traffic 工作区完成明暗主题和 wide/medium/minimum 三档响应式布局验收。

## 安全声明

Hackermes 仅用于自己拥有或已获得明确授权的目标。主动评估工具仍受授权范围、固定计划、一次性批准、独立 ToolHost 校验、证据记录与审计链约束。
