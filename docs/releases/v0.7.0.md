# Hackermes 0.7.0

Hackermes 0.7.0 完成 Stage 7 正式基线，把网页调试、流量分析、受控工具调用和授权评估整合为
可安装、可升级、可恢复、可审计的桌面工作台。

## 本版本重点

- 新增完整的授权评估工作区：范围、固定计划、一次性审批、执行、取消与撤销。
- 新增证据 SHA-256 验证、Finding 创建与人工复核、连续 HMAC-SHA256 审计链验证。
- 支持 JSON、Markdown 和 HTML 评估报告导出。
- CLI 与 Agent 使用同一个持久化控制面，并完成真实注册入口的全链路验收。
- Assessment 存储支持写穿透临时文件、上一份有效备份、损坏留存和自动恢复。
- 中断的 Queued/Running 任务会在重启后标记为 Failed 并写入恢复审计记录。
- Windows 安装器支持逐文件校验、暂存安装、原子升级、上一版本保留与回滚。
- DOM 标签打开时自动读取当前页面，树和详情面板重新布局并提供独立滚动与可复制文本。
- 启动脚本保持“只启动、不构建”，并对短暂的文件占用进行有限重试。

## 下载

- `Hackermes-0.7.0-windows-x64.zip`：Windows 10/11 x64 自包含安装包。
- `Hackermes-0.7.0-linux-x64.tar.gz`：Linux x64 自包含预览包。
- `SHA256SUMS.txt`：发布归档的 SHA-256 校验值。

## 安装、升级与恢复

Windows 解压后运行 `Install-Hackermes.ps1`。安装器会验证 `release-manifest.json`，将新版本复制到
暂存目录后原子切换，并在 `.previous` 保留上一版本。运行
`Install-Hackermes.ps1 -RestorePrevious` 可回滚。安装、升级、回滚和普通卸载默认保留
`%LOCALAPPDATA%\Hackermes` 下的用户配置、密钥和工作数据。

Linux 解压后运行 `chmod +x install.sh && ./install.sh`。Linux 需要发行版提供 Avalonia 桌面依赖和
WebKitGTK；WebView2 专属 CDP 能力仍仅限 Windows。

## 已知限制

- Linux 桌面端仍属于预览状态。
- 多用户身份提供方、复杂规则表单和外部签名式报告属于后续增强项。
- 第三方工具仅在许可和再分发信息明确时进入公开发布包。

## 安全声明

Hackermes 仅用于自己拥有或已经获得明确授权的目标。Agent 主动工具调用必须经过精确范围、固定计划、
一次性审批和独立 ToolHost 校验。
