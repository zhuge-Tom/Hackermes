# Hackermes 0.11.0

Hackermes 0.11.0 把内置 AI 助手做成可完成授权评估调查的 Agent：能观察、调用工具、
压缩长上下文，并把观测写成待复核 Finding。不新增利用/破坏类 Adapter。

## 助手能力

- 授权评估 hunt/record 协议；`page_security_snapshot` 与 `packet_analyze` 输出同一套观测码。
- Finding 可挂 page/packet 观测，不必先跑 ToolHost；`authorize_and_run` 回传 Evidence id。
- 浏览器工具改为 typed schema；入参校验；只读并行默认 4；`page_eval_read` 只读检查。
- 证据台账、评估案件注入、`agent_subtask` 有界子任务、recon stdout 结构化观测。
- ACP：摘要保尾与 spill、按证据优先级选压缩区间、预算计入 system/工具 schema、截图进多模态请求。
- 首次启动写入默认可关闭的「授权评估」Skill，系统提示带分域工具目录。

## 测试与构建
