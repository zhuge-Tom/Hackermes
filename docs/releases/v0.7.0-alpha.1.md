# Hackermes 0.7.0-alpha.1

这是 Hackermes 首个公开的 Stage 7 预发布版本，重点是把已有网页调试与流量工作台
整理成可安装、可审计、可由人工与 Agent 共同操作的桌面应用。

## 本版本内容

- 完成 Stage 2/3 的浏览器、CDP、Page Agent、DOM、网络和统一动作链路。
- 完成 Stage 5/6 的数据包拦截、编辑、重放、规则、归档、Repeater、Comparer、标注和审计基础功能。
- DOM 检查器支持树形结构、页面拾取、双向悬停/点击定位和 CSS 规则编辑。
- 内部浏览器支持直连与 Burp `127.0.0.1:8080` 代理切换、监听检测和已知页面遥测过滤。
- AI 设置支持 OpenAI 兼容 API、自动获取模型、三档权限模式、上下文压缩、持久记忆与 Skill 工作流。
- 新增授权范围、不可变计划、一次性审批票据、独立 ToolHost、证据与审计链路。
- 安全工具菜单提供内置编码/哈希功能和受控教学终端；未内置工具保留说明和缺失原因。
- 新增 Windows DPAPI 与 Linux 用户级 AES-256 密钥库。
- 新增新的 Hackermes 应用图标。

## 性能与存储

- 开发运行目录仅保留 Windows x64 和 Linux x64 相关运行时资源。
- 响应体默认捕获上限从 2 MiB 调整为 512 KiB。
- 流量历史默认策略调整为 2,000 条、64 MiB。
- 页面关闭时释放 Network/Console 订阅与缓存。
- 避免保存流量历史时反复深复制响应体和重复解压验证。

## 下载

- `Hackermes-0.7.0-alpha.1-windows-x64.zip`：Windows 10/11 x64，
  自包含 .NET Runtime，包含安装/卸载脚本。
- `Hackermes-0.7.0-alpha.1-linux-x64.tar.gz`：Linux x64 预览包，
  自包含 .NET Runtime，包含用户级安装/卸载脚本。
- `SHA256SUMS.txt`：两个安装归档的 SHA-256 校验值。

## 平台说明

Windows x64 是完整验证平台，需要 Microsoft Edge WebView2 Runtime。Linux x64 当前属于
预览：应用和 ToolHost 可跨平台构建，密钥库已有 Linux 实现，但 WebView2 专属 CDP、
部分终端与第三方安全工具仍以 Windows 为主要验收目标。

## 第三方工具

公开发布附件只包含清单中具备来源与许可信息的组件。标记为
`redistribution-unverified` 的本地二进制不会进入公开发布包；对应菜单入口仍会显示为
“未内置”。详情见包内 `THIRD-PARTY-NOTICES.md` 和 `app/tools/manifest.json`。

## 验证情况

- 所有项目 Release 源码编译通过。
- Windows x64 自包含程序已进行真实启动与响应检查。
- Linux x64 自包含程序已完成交叉发布和归档结构检查；当前 Windows 构建机无法执行 Linux GUI 运行验收。
- 自动化测试集已完整执行：240/240 通过，无跳过或失败。

## 安全声明

本工具仅用于自己拥有或已获得明确授权的目标。Agent 主动工具调用必须经过精确范围、
固定计划、一次性审批和 ToolHost 校验。使用者应遵守当地法律、目标系统规则及第三方工具许可证。
